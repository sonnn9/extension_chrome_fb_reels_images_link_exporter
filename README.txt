FACEBOOK REELS LINK EXPORTER
============================

Chức năng:
- Mở trang Facebook Reels, ví dụ: https://www.facebook.com/DJ.HYENA.VN/reels/
- Bấm extension -> Bắt đầu quét
- Extension sẽ tự cuộn trang để Facebook load thêm reel
- Gom toàn bộ link reel đang tìm được
- Xuất ra file CSV để tải về

Cách cài:
1) Giải nén file ZIP.
2) Mở Chrome -> chrome://extensions/
3) Bật Developer mode.
4) Chọn Load unpacked.
5) Trỏ tới thư mục fb_reels_link_exporter.

Lưu ý:
- Bạn nên đăng nhập Facebook trước.
- Trong lúc quét, giữ nguyên tab Facebook đang mở.
- Facebook có thể thay đổi giao diện/DOM theo thời gian, khi đó selector có thể cần chỉnh lại.
- Extension hiện ưu tiên lấy các link có dạng /reel/, /reels/, /videos/ hoặc /share/r/ xuất hiện trên trang.
